# Public release boundary

The owner authorised a public repository for the capstone. This is a new clean checkout with a new history, assembled from an explicit allowlist. It is not a push of the business workspace or its history.

Included: independently written Python capstone modules, their core tests, required prompts, the approved 30-entry public support dataset, authored evaluation/demo data, the five required deliverables and six selected UI screenshots. The source selection record lists exact copied paths/hashes; the final manifest lists published files.

The public FAQ preserves each runtime question, answer, paraphrase, status and public link. Internal source-location/provenance fields were removed. No original FAQ collection, wireframe copy, private tutor, student-map engine, assessment algorithm, account/payment application or business repository is included. The homepage HTML/JavaScript/styles, Python web wrapper and raw brand assets are excluded. Public branding appears only in six individually selected illustrative screenshots.

No `.env` or example environment file, API key, GitHub token, virtual environment, embedding cache, operational log, browser profile or real student record is included. Runtime caches/logs generated for verification are excluded from both Git and the submission ZIP. Credentials used for the clean-package demo are passed only in process environment, without a key file copy. The repository's first commit contains only the scanned selection; workspace history is not imported.

Only metadata-safe, authored transcripts are published. Existing historical data is projected into explicitly selected evidence, with version labels preserved; no whole evidence directory or source snapshot tree is copied. Fictional family names in demo records are fixtures, not actual student data. Key-like test strings in unit tests are synthetic; no actual credential value is permitted.

The final publication scan checks literal configured credentials, common key/token patterns, private paths, unexpected file types, symlinks and exact membership. It is a scoped pre-publication check, not a universal security guarantee. The publication and ZIP must pass it before upload. Never replace this selection by archiving the entire local workspace.
